# Sistem-panen-luna
Program sederhana untuk menghitung total hasil panen dan menghitung harga setelah diskon, dibuat sebagai tugas mata kuliah Algoritma Pemrograman.

Cara Menjalankan
Pastikan Python sudah terpasang
Jalankan perintah: python hitung_panen.py
Program akan menampilkan total hasil panen dalam kg
