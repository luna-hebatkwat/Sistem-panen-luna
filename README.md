# Sistem Pencatatan Hasil Panen

## Deskripsi

Proyek ini merupakan program Python sederhana untuk menghitung total hasil panen dan menghitung nilai setelah diberikan diskon. Program dibuat sebagai bagian dari pembelajaran Git dan GitHub pada mata kuliah Algoritma dan Pemrograman.

## Fitur

* Menghitung total hasil panen.
* Menghitung diskon.
* Menggunakan fungsi Python.
* Menggunakan Git untuk mengelola versi kode.

## Cara Menjalankan Program

1. Pastikan Python sudah terinstal.
2. Clone repository.
3. Masuk ke folder proyek.
4. Jalankan program dengan perintah:

```bash
python panen.py
```
